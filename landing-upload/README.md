# Bridge onboarding prototype

Static multi-page prototype prepared for GitHub Pages.

## Files

- `index.html` - complete landing page and upload entry point
- `onboarding.html` - signup / workspace creation journey
- `workspace.html` - final Workspace / Details state
- `workspace-tags.html` - auto-tagging / Tags state
- `css/` - shared styles
- `js/` - page-specific interactions
- `assets/` - extracted image assets

## Deploy on GitHub Pages

Upload the **contents of this folder** to the root of the target repository.
Keep the `css`, `js` and `assets` folders intact.

Then enable GitHub Pages from the repository branch/root if it is not already enabled.

No build step or package manager is required.
